# Lyton Mupanga — Professional Website

Static HTML/CSS/JS website designed for GitHub + Netlify deployment.

## Before deploying
Keep the existing image files from the current repository in the project root. The new site references:
- `lyton-mupanga.jpg`
- `lyton1.jpg` through `lyton26.jpg`
- `lyton27.JPG`, `lyton28.JPG`, `lyton29.jpg`, `lyton30.jpg`, `lyton31.jpg`

The package intentionally does not replace your photographs.

## Deploy
Replace the existing `index.html`, add the folders/files in this package to your GitHub repository, and commit to `main`. Your existing Netlify site is already connected to that repository, so the push should trigger a production deployment automatically.

## Important
- The site uses the current Netlify URL: `https://lytonmupanga.netlify.app/`.
- If you later buy a custom domain, update every canonical URL, Open Graph URL/image URL, JSON-LD URL, robots.txt and sitemap.xml to the new domain.
- Contact form uses Netlify Forms. In Netlify, enable automatic form detection under Forms if it is not already enabled.
- The social links included are only the profiles whose exact URLs are known from the existing website. Add other exact profile URLs when you have them; do not guess them.
